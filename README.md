# Youtuber Zoom

Extensão de navegador que permite **ampliar e dar zoom em vídeos do YouTube** para uma experiência de visualização mais confortável.

- Javascript e CSS.

## Como baixar?

1. Clone o repositório:
   ```bash
   git clone https://github.com/pietrohansel/youtube-zoom.git
   ```
2. Acesse chrome://extensions/.
3. Ative o Modo do desenvolvedor
4. Clique em Carregar sem compactação e selecione a pasta do projeto.
5. Abra o YouTube e use a extensão.
